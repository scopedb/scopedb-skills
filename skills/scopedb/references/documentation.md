# Find and use official documentation

Use this workflow when syntax, function behavior, CLI options, or version support needs verification. Read only the pages relevant to the task and reuse material already checked in the current session.

1. Start with a page linked from the active task guide. For an unmapped topic, check the [documentation index](https://www.scopedb.io/llms.txt) or the [sitemap](https://www.scopedb.io/sitemap.xml), then follow discovered URLs rather than constructing page paths by guesswork.
2. Read the relevant page content to verify exact syntax, function signatures, and semantics rather than relying on index descriptions or search snippets.
3. Confirm applicability to the installed CLI (`scope version` and `scope --help`) or target ScopeDB release. For chart validation and rendering, follow the public ScopeView package in the [rendering guide](visualize/runtime.md).
4. Link the official documentation pages supporting language or product conclusions. If a page cannot be reached or a version detail remains unresolved, state the gap and label any resulting assumption.

Keep general language and product reference material in official documentation, and use skill references for task workflows and ScopeDB-specific rules.
